- change the name, description and image of individual structure elements;
- scale the tree;
- move both individual elements and entire branches within the tree;
- delete both individual elements and entire branches within the tree;
- search for an element within a structure by id;
- save the structure to a file;
- load a tree from a file;
- include structure file in html for default loading;
